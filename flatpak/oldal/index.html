Gozie Commander – Flatpak

A Gozie Commander Flatpak-tárolója. Innen telepítve a program a Szoftverközponttal (Discover, GNOME Szoftverek) vagy a flatpak update paranccsal frissül. Legújabb változat: @VER@.

Telepítés

A gomb egy .flatpakref fájlt tölt le; megnyitva a Szoftverközpont telepíti. Terminálból:

flatpak install --user @URL@/hu.gozie.commander.flatpakref

Frissítés: a Szoftverközpont magától jelzi, vagy

flatpak update hu.gozie.commander

A futtatókörnyezet (org.freedesktop.Platform) a Flathubról érkezik, ezt a telepítés magától hozzáadja. A csomagok GPG-kulccsal vannak aláírva.

English: the Flatpak repository of Gozie Commander. Click Telepítés (Install) or run the command above; updates arrive through your software center or flatpak update.
